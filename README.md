## Overview

This project was completed during a **Data Technician Bootcamp** and focuses on analyzing global health data using **Tableau**. Using the Gapminder Health dataset, I created an interactive dashboard to explore health trends, population demographics, and regional disparities across countries and continents.

7
The dashboard enables users to investigate key health metrics such as life expectancy, BMI, population growth, and disease-related indicators through interactive visualizations and filters.
